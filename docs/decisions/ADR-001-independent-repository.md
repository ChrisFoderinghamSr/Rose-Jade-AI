# ADR-001: Independent Rose Jade Repository

## Status

Accepted

## Decision

Rose Jade AI will be developed in an independent repository separate from the Chris Foderingham portfolio.

## Reason

Separating the AI platform from the portfolio provides:

- Independent development
- Independent deployment
- Independent versioning
- Independent security controls
- Independent infrastructure
- Clear ownership boundaries
- Future product scalability

## Consequence

The portfolio will communicate with Rose Jade through a defined external application/API boundary rather than containing the AI platform itself.
